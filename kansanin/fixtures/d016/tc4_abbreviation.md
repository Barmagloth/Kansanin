# Требования к хранению данных

## Архитектура хранения

Все данные приложения хранятся в базе данных PostgreSQL.
База данных должна поддерживать репликацию для отказоустойчивости.

## Резервное копирование

Резервные копии БД создаются каждые 6 часов.
Администратор должен проверять целостность БД после восстановления.
Хранилище резервных копий должно быть географически распределено.
