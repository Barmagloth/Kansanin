# Требования к системе

## Производительность

Система должна обрабатывать входящие запросы не более чем за 200мс.

Кэш должен хранить последние 1000 записей.

База данных должна поддерживать ссылочную целостность.

## Безопасность

Модуль аутентификации должен проверять учётные записи пользователей.
