# Системные требования

## Обработка данных

Система передаёт состояние агенту, и он должен применить его к процессу.

Сервис должен отправить запрос обработчику и компонент должен записать его в буфер.

## Аутентификация

Модуль аутентификации должен проверить токен в хранилище, и он должен отклонить его при несоответствии.
