# Спецификация требований

## Требования к обмену данными

Система должна использовать Kafka для асинхронного обмена сообщениями между сервисами.
Все события должны публиковаться в формате Avro.

## Требования к интерфейсу

Пользовательский интерфейс необходимо реализовать на React с использованием TypeScript.
Интерфейс должен поддерживать мобильные устройства с экранами от 320px.

## Требования к производительности

Система должна обеспечивать время отклика не более 500 мс для 95% запросов.
