# Требования к системе

## Управление доступом

Пользователь должен пройти проверку прав перед началом работы.
Система проверяет права доступа при каждом запросе.

## Безопасность

Для доступа к защищённым ресурсам клиент предоставляет токен.
После успешной проверки клиент получает сессию.

## Хранение данных

Все данные хранятся в базе данных PostgreSQL.
Резервные копии БД создаются каждые 6 часов.
Администратор должен проверять целостность хранилища после восстановления.
